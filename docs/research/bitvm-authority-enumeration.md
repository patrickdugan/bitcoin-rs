## 1. Specify the HF acceptance relation before enumerating it

Let `D` be a descriptor, `s` its state commitment, `A = H(D)`, and `K(D,s)` its
canonical receiving commitment. A consensus-native design should expose:

```
HF_Accept(K, T, witness) =
    Bind(K, D, s)
    AND Verify_D(proof, A, s, H_context(T))
```

`Bind` authenticates the full descriptor and state against the funded output.
`Verify_D` includes the retained parent guard and the exact authorized output
record. Its proof parameters and program identity come from authenticated data.
`H_context` binds the real input context and outputs. The execution version and
resource bounds belong to the descriptor.

This interface turns the research question into a concrete counterexample:

```
Find a fixed funded authority K, transaction T, and witness w such that
HF_Accept(K,T,w) = true while ParentPolicy(K,T) = false.
```

Selecting a different permissive program produces a different authority under
a correct binding scheme. The arena must preserve the original funded target
when scoring an authorization escape. Otherwise a solver can satisfy the task
by changing what it was asked to attack.

There are several search spaces. Circuit syntax contains aliases. Canonical
programs quotient the explicit normalization rules. Semantic policies quotient
all equivalent authorization relations in a fixed bounded environment. The
corresponding curve points supply cryptographic commitments to those objects.
Their coordinates do not supply an authorization-loss function.

## 2. A complete small enumeration

The study enumerated topologically numbered NAND circuits with two permission
inputs and one independent selector input. Each gate chooses an unordered pair
of existing wires, with repetition allowed. Permission is the last gate's
output. Selector is input 2. All declared NAND gates must reach the permission
output. Unused external input declarations are omitted, while the declared
external arity remains three.

For `g` NAND gates before reachability filtering, the number of wire sequences is

```
N(2,g) = product_{i=0}^{g-1} choose(2+i+1, 2).
```

| NAND gates | Raw sequences | All gates reachable | Cumulative canonical programs | Distinct permission functions |
|---:|---:|---:|---:|---:|
| 1 | 3 | 3 | 3 | 3 |
| 2 | 18 | 9 | 12 | 9 |
| 3 | 180 | 45 | 51 | 13 |
| 4 | 2,700 | 333 | 273 | 15 |
| 5 | 56,700 | 3,393 | 1,851 | 16 |

Totals: 59,601 raw sequences and 3,783 reachability-qualified sequences.
Canonical hashing merges structural duplicates across and within gate counts.
The remaining 1,851 identities cover all 16 Boolean permission functions on two
inputs. The full corpus is in `evidence/circuits.jsonl`.

The always-true permission function accounts for 285 of the 1,851 canonical
programs, or 15.397%. Uniformly sampling these program identities therefore gives
that semantic policy 2.464 times the weight it receives under a uniform draw
from the 16 functions. This is a property of this bounded grammar and sampling
rule. It is not an estimate of real-world policy prevalence or exploit rate.

This matters for an agent benchmark: syntactic diversity can overstate semantic
coverage. Train/evaluation partitions should group graph aliases, and should
also report results by semantic policy where exact equivalence is tractable.

For a larger illustrative bound with eight available inputs and 24 NAND gates,

```
log2 N(8,24) = 178.72811126794605.
```

This counts topologically labelled, unordered-operand wire sequences before
reachability and canonicalization. It is not the size of the executable CPA
profile, an entropy estimate, or an attack work factor.

## 3. Identity fibers give a direct soundness criterion

For fixed environment data, let `A_D` be the set of actions authorized by
policy `D`. Let `E(D)` denote an identity a verifier uses as interchangeable
with another descriptor. A necessary condition for safe interchangeability is

```
E(D) = E(D')  =>  A_D = A_D'.
```

Equivalently, every identity fiber must lie within one semantic equivalence
class. A directional delegation rule can use the weaker inclusion
`A_child subset_of A_parent` when that inclusion is independently enforced.

Proof: if a fiber contains different acceptance sets, their symmetric
difference contains an action. That action has different policy meaning under
the two descriptors despite the shared identity. A verifier that lets the
spender substitute either descriptor cannot preserve both policies. The
counterexample requires the substitution interface to exist; a separate exact
script commitment can prevent that interchangeability.

### A concrete topology-erasure counterexample

Consider

```
C1(a,b) = NAND(a, NAND(a,b)) = not(a) OR b
C2(a,b) = NAND(b, NAND(a,a)) = a OR not(b).
```

Both use two NAND nodes with the same input-node types. Their wiring differs.
On inputs ordered `00,01,10,11`, their truth tables are `1101` and `1011`.
At `a=1,b=0`, C1 rejects and C2 permits.

An identifier that commits only to a multiset of gate/input types aliases this
pair. This happens before hashing; a cryptographically strong outer hash cannot
restore omitted wiring. The actual CPA ProgramIDs are different.

Across this study's corpus, the deliberately weakened histogram identifier has
10 buckets. Nine contain multiple permission functions, accounting for 1,850
programs. These are ambiguous identity buckets. The count does not mean that
1,850 funded CPA programs are exploitable, and it is not a collision in SHA256.

Input positions must also remain semantic. Identifying `INPUT(0)` with
`INPUT(1)` would let a public-choice bit impersonate an authorization bit in a
profile where those roles differ. CPA preserves those input indices.

## 4. Public tweaks collapse to one unknown anchor

The current research output uses a fixed NUMS internal point P and Taproot's
public tweak. For a circuit/state-specific Merkle root m_i,

```
t_i = H_TapTweak(x(P) || m_i)
Q_i = P + t_i G.
```

The point is checked for the usual exceptional cases. All t_i are public.
BIP341 defines this construction and the NUMS technique [341].

For every enumerated authority,

```
Q_i - t_i G = P.
```

Thus a catalogue of such public keys supplies repeated transforms of the same
unknown discrete logarithm p. For arbitrary known coefficients a_i,

```
sum_i a_i Q_i = (sum_i a_i) P + (sum_i a_i t_i) G.
```

If the anchor coefficient vanishes, the relation has a publicly known scalar.
A remaining anchor coefficient leaves a discrete-log problem for P. Enumerating
known tweaks does not produce independent equations in independent secrets.

The study reconstructed all 32 sampled CPA output keys from their actual
Taproot roots and verified that removing each public tweak returns the same
NUMS point. It recovered no private logarithm for that point.

### Shared-anchor compromise propagates

If any full derived secret q_i becomes known, then `p = q_i - t_i (mod n)`.
Every other derived secret follows as `q_j = p + t_j`. With BIP340 x-only keys,
include the known output parity: `p = epsilon_i q_i_even - t_i (mod n)`.
The study tests this identity with an explicitly known synthetic anchor secret.

This is a blast-radius result. It is not an observed compromise of the NUMS
anchor. An independently derived hash-to-curve internal point per policy would
change that shared-anchor structure. Such a profile needs a specified suite
and domain separation, including exceptional-case rules [9380].

### Public hash-to-scalar is a different construction

For the intentionally insecure alternative

```
q_C = H_scalar(Encode(C))
Q_C = q_C G,
```

anyone who has the public circuit computes the signing scalar. Hash output
length supplies no secret entropy conditional on that public circuit. The study
checks 32 planted examples. A distinct secret or a proof-only spending rule
would have to supply authorization in such a design.

### Related-key signatures need key binding

An unprefixed Schnorr variant has `sG = R + eP` with `e=H(R || message)`.
For known a, `(R, s+ea)` verifies under `P+aG` for that same message. BIP340
includes the public key in the challenge to address this related-key issue
[340]. The study includes a deliberately unprefixed algebraic negative control
and checks that changing the challenge defeats that simple translation.
No BIP340 signature forgery is demonstrated.

## 5. What convergence can mean

Assume an ideal b-bit commitment hash. With q distinct fresh candidate queries,
the probability of hitting one fixed target digest is at most `q/2^b`.
For M fixed targets, the union bound is `Mq/2^b`. Finding any collision among q
candidates has a birthday bound `q(q-1)/2^(b+1)`. These address different attack
objectives. The candidates must also induce an exploitable policy change.

A monitor that compares only b prefix bits deliberately reduces its comparison
space. Expected geometric waiting time for a chosen prefix is `2^b` under the
same independent uniform model. Full consensus commitment equality remains a
separate check. A prefix collision can mislead a human or monitoring cache while
leaving the funded script binding intact.

Numerical coordinate proximity and a matching prefix do not reveal a scalar
difference. The generic-group discrete-log lower bound is square-root in the
largest prime order, with a success bound of order `q^2/n` in the appropriate
model [Shoup]. This statement is limited to generic attacks. The experiment
supplies no new representation-specific secp256k1 attack.

The useful search geometry lies in authorization sets. On a finite action
universe U with measure mu, define

```
d_plus(D,D') = mu(A_D' \ A_D).
```

It measures the additional authority introduced by a replacement. It satisfies
an asymmetric triangle inequality because

```
A_D'' \ A_D subset_of (A_D' \ A_D) union (A_D'' \ A_D').
```

An equality `E(D)=E(D')` with `d_plus(D,D')>0` is an identity-substitution witness
when the verifier permits interchangeability. A symmetric-difference distance
supplies a metric after quotienting identical acceptance sets. No analogous
semantic meaning is assigned to nearby public-key coordinates.

### A convergence statement for bounded attack search

Let B_k bound circuit size, witness size, transaction size, and execution cost.
Make these finite bounds nested. Exhaustively enumerate the bounded cases and
record the greatest verified policy violation `V_k`, with zero for no violation.
Then `V_k` is nondecreasing. For a fair enumeration covering every finite case,
its limit equals the supremum of the losses over those finite cases.

This follows from set inclusion and the definition of a supremum. It makes no
claim that any finite zero result proves the unbounded implementation safe.
An actual HF verifier and an independent policy oracle are required to turn
this mathematical schedule into an Arena measurement.

## 6. Delegation is an intersection of accepted actions

At one level, let P be the retained parent guard, C the verified child relation,
and F the authenticated freshness/scope condition. For a fixed transaction,

```
A = P intersect C intersect F.
```

At multiple levels, require every retained parent guard to hold on the same
final action record. The accepted set lies within their intersection. This is
the invariant an agent should attempt to falsify.

The CPA experiment's exact public inputs `(a,b,selector)` admit the parent
spend when `a AND b` holds and `selector=0`. Selector 1 has a valid child trace
but chooses a 9,000-sat payout against the 8,000-sat parent cap. That witness
fails. A different authority with a 9,000-sat cap accepts the corresponding
fresh witness. Its address differs.

Within this small environment, the 16 permission functions form the Boolean
lattice of subsets of four input assignments. This supplies an exact
refinement oracle. A learned control policy can rank which candidate to test;
the lattice inclusion or direct witness checker owns the pass/fail decision.

Cumulative budgets require an authenticated state transition. A sum of output
allowances must be bounded by the consumed allowance. Two independent coins
paying the same address do not supply shared state merely through their common
address. Epoch labels also need authenticated lineage before they can impose
global freshness across independently funded copies.

### Field-packing alias

A deliberately unsafe proof-input encoder reduces an arbitrary 256-bit digest
to one field element modulo a smaller prime r. Then x and x+r can alias.
The study uses `r=2^255-19`, `x=17`; both integers fit in 256 bits. Their
128-bit limb pairs differ. Injective, range-checked packing preserves the bytes.

This is a deterministic encoder alias. Producing a corresponding adversarial
transaction digest still needs a path through the proof relation and actual
transaction check. The test does not find a SHA256 preimage for the second value.

## 8. Arena scenario contract

`scripts/tests/data/bitvm-authority-enumeration/arena_scenarios.jsonl` proposes ten families with explicit evidence levels.
Measured existing-CPA rejections remain separate from planted insecure-model
failures and unimplemented HF hypotheses. The native Arena API was unavailable,
so this JSONL is an import contract rather than a tested adapter.

Each adversarial episode should freeze the target descriptor/state/output and
retain an independent policy oracle. A successful attack requires a verified
unauthorized effect against that fixed target. A permissive substitute target
receives no attack credit. Test-only mutants must be marked in every receipt.

Record canonical ProgramID and AuthorityID, target outpoint, gate budget, exact
witness, altered policy field, validator result, parent-invariant result, and
reproduction bytes. Count discovery of a planted mutant separately from escape
against an unmodified implementation. Group equivalent graphs during dataset
splits. Report worst-case witnessed loss alongside sampling-distribution rates.

The published proxy's four actions can serve as control-profile labels. Their
actual outcomes require the native adapter. A proof-preserving attested bundle
addresses context and verifier binding. Monitoring handles observable liveness
and resource conditions. Funding eligibility should be gated by exact execution
profile support. Synthetic score ranks cannot establish consensus safety.
